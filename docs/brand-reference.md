## 참고 사이트의 색상

| 용도                | 값        |
| ------------------- | --------- |
| 주 색상             | `#E31E24` |
| 진한 주 색상 / 호버 | `#C91A1F` |
| 보조색 / 진한 배경  | `#1A1A1A` |
| 본문                | `#333333` |
| 보조 본문           | `#666666` |
| 옅은 배경           | `#F8F9FA` |
| 흰색 배경           | `#FFFFFF` |
| 구분선              | `#E0E0E0` |

색상은 [참고 CSS의 :root 변수](https://3000-i2jfuj3rxcmkpzyqsxxjn-2e1b9533.sandbox.gensparksite.com/css/style.css)에서 확인한 값입니다. 로고 PNG에서 추측한 색상이나 별도의 공식 브랜드 매뉴얼 값으로 간주하지 않습니다.

참고 사이트는 `linear-gradient(135deg, #e31e24 0%, #c91a1f 100%)`도 사용합니다. 페이지 글꼴은 `Noto Sans KR`, 굵기는 300·400·500·700·900이며 로고 글자는 이미지에 포함되어 있습니다.

## 재사용

- 기계 판독용 명세: `public/brand/brand.json`
- 재사용할 CSS 변수: `public/brand/tokens.css`의 `.kangteacher-brand`
- 이번 변경 범위는 에셋과 브랜드 값 확보입니다. 기존 홈페이지의 색상, 헤더·푸터, 파비콘 교체는 아직 적용하지 않았습니다.
- 참고 사이트의 후기, 상담 시간, 신청 폼 및 외부 스크립트는 이번 브랜드 자료에 포함하지 않았습니다.
